<objective>
Transform the static code view into a living, breathing visualization that TEACHES rhythm.

Currently: Dead text. Syntax-highlighted but lifeless. Kids can't see the connection between the grid and the code.

After: Each line of code bounces when its sound triggers. Pattern characters (x and ~) are visually distinct — x is bright and bold, ~ is dim and small. A cursor moves through the pattern string showing exactly WHERE in the beat we are. Color borders connect each code line to its sequencer row.

Purpose: The code view becomes a second way to read the rhythm. Grid teaches spatial patterns, code teaches symbolic notation. Together they build music literacy.

SAFETY NOTE on innerHTML usage: The code prop is exclusively generated by composeLayerCode() in layers.js — never user-supplied HTML. Prism.highlight() output contains only span class=token wrappers for syntax tokens. This is a safe, controlled use of innerHTML for syntax coloring, same as the existing CodeView component.
</objective>

Complete rewrite of CodeView to support:
1. Per-line color borders matching sequencer rows
2. Line bounce animation when row triggers on beat
3. Pattern character parsing (x = bright, ~ = dim)
4. Moving cursor through pattern string on beat

The component now accepts beatStep and stepCount props from App.jsx.

Key design decisions:
- renderPatternLine() parses .struct("x ~ x ~") and wraps each character in a span
- pattern-hit vs pattern-rest classes for x vs ~ styling
- pattern-cursor class highlights the current beat position in the pattern string
- code-line-bounce class triggers translateY animation on beat
- Color border via inline style using ROW_COLORS
- Prism highlighting preserved for non-pattern parts (function names, punctuation)
- All innerHTML usage is safe: only Prism.highlight() output on internally-generated code

IMPORTANT: The innerHTML usage is SAFE because:
- The code prop comes from composeLayerCode() — generated internally, never from user input
- Prism.highlight() only produces span.token wrappers
- This is the same pattern as the existing CodeView
