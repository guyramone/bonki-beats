
Replace the useEffect at lines 344-370 with:

```js
// --- Beat Position Tracking (rAF — drift-free) ---
useEffect(() => {
  if (isPlaying) {
    playStartRef.current = performance.now();
    const msPerStep = 60000 / bpm;

    const tick = () => {
      const elapsed = performance.now() - playStartRef.current;
      const currentStep = Math.floor(elapsed / msPerStep) % stepCount;
      setBeatStep(currentStep);
      rafRef.current = requestAnimationFrame(tick);
    };

    rafRef.current = requestAnimationFrame(tick);

    return () => {
      if (rafRef.current) cancelAnimationFrame(rafRef.current);
      rafRef.current = null;
    };
  } else {
    if (rafRef.current) {
      cancelAnimationFrame(rafRef.current);
      rafRef.current = null;
    }
    setBeatStep(null);
  }
}, [isPlaying, bpm, stepCount]);
```

**Why this is better:**
- `requestAnimationFrame` fires at display refresh rate (~60fps), giving smooth visual updates
- `performance.now()` gives microsecond-accurate timestamps
- Step position is COMPUTED from absolute elapsed time, not incremented — so it can never drift
- If the browser tab is backgrounded, rAF pauses and resumes without accumulating drift
