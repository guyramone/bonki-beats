**1. Install Prism.js:**

```bash
cd homie-beats && npm install prismjs
```

Prism.js is 2KB core + JS grammar. Per research: use string-based `Prism.highlight()` API, NOT the DOM-based `highlightElement()`. This avoids flicker and works with React's virtual DOM.

**2. Create `src/components/CodeView.jsx`:**

Props:
- `code` — The full Strudel code string to display (from composed layers)
- `onCodeClick` — Callback when user clicks in the code area (triggers Bonki message)
- `flashLine` — Line number to flash (0-indexed, or null). Used for highlighting the line that just changed.

Component implementation:

Use `Prism.highlight(code, Prism.languages.javascript, 'javascript')` to generate a highlighted HTML string. This is the Prism string-based API — no DOM manipulation.

**SAFETY NOTE on innerHTML rendering:** The `code` input is exclusively our own generated Strudel pattern code produced by `composeLayerCode()` in `layers.js`. It is never user-supplied HTML. Prism's output contains only `<span class="token ...">` wrappers for syntax tokens. This is a safe use of innerHTML. Document this reasoning in a code comment.

Split the highlighted output by newline characters into an array of line strings. Render each line in a `<div>` element. Apply a `.flash` CSS class to the line matching `flashLine` prop, with a 600ms timeout to remove it.

Include:
- A header bar with "STRUDEL CODE" label and a Copy button
- Copy button uses `navigator.clipboard.writeText(code)` with a fallback for older browsers
- Per-line rendering for flash support
- Flash effect triggered via useEffect watching flashLine changes

**3. Create `src/styles/code-view.css` — Dark terminal aesthetic:**

Monokai/One Dark inspired token colors. Background `#111111` (darker than app's `#0a0a0a` secondary). Monospace font. Standard syntax highlighting colors.

CSS structure:
- `.code-view` — Flex column container, dark background, rounded border
- `.code-view-header` — Title + copy button row, even darker background `#0d0d0d`
- `.code-view-title` — 10px uppercase label "STRUDEL CODE" in muted gray
- `.code-view-copy` — Small bordered button, highlights on hover with accent-primary
- `.code-view-pre` — Monospace, 12px, #abb2bf text, scrollable, flex:1
- `.code-line` — Per-line wrapper, default transparent background
- `.code-line.flash` — Flash animation: golden glow that fades over 0.6s

Prism token colors (One Dark inspired):
- `.token.keyword` — purple `#c678dd` (const, let, if, return)
- `.token.string` — green `#98c379` (quoted strings)
- `.token.number` — orange `#d19a66` (numeric literals)

- `.token.punctuation` — default text `#abb2bf` (parens, braces)
- `.token.comment` — dim gray italic `#5c6370`
- `.token.boolean` — orange `#d19a66`
- `.token.regex` — red `#e06c75`

The code view shows the `composeLayerCode` output WITHOUT the `.gain()` wrapper (volume is a playback concern, not a code concern). This gives users the real pattern code they'd paste into strudel.cc.

**2. Track flash line for cell toggle animation:**

Add `flashInfo` state: `const [flashInfo, setFlashInfo] = useState(null)`.

In `handleToggleCell`, after updating the grid, calculate which line in the code corresponds to the toggled row. Since `sequencerToPattern` generates one line per sound row inside `stack()`, the line mapping is:
- Row 0 → line 1 (first line after `stack(`)
- Row 1 → line 2
- Row N → line N+1

Set `setFlashInfo({ line: rowIndex + 1, key: Date.now() })` — using a timestamp key to force re-trigger even if the same row is toggled twice.

**3. Handle code click (read-only Bonki message):**
