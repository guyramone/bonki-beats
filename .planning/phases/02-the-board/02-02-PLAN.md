Build the eclectic preset system with 15+ genre presets, Bonki album cover art, horizontal scroll gallery, and Bonki speech bubble reactions -- the record-crate browsing experience.

```javascript

  genre: 'Lo-fi Hip-hop',     // Genre subtitle
```

Export a `BonkiCover` component: `<BonkiCover variant="lofi" />` renders a 24x24 SVG.

**1. Wire presets into App.jsx:**

- Import `PresetGallery` and `BonkiSpeech` components
- Import `PRESETS` from utils/presets.js (for reference if needed)
- Add `bonkiMessage` state: `const [bonkiMessage, setBonkiMessage] = useState(null)`

**2. Preset select handler (tap to preview):**

`handlePresetSelect(preset)`:
- Set BPM to preset's ideal tempo: `setBpm(preset.bpm)` and `evaluate(\`setcps(${bpmToCps(preset.bpm)})\`)`
- Evaluate just the preset code as a preview (replaces current playback): `evaluate(preset.code)`
- Set `isPlaying(true)`
- Show Bonki speech bubble: `setBonkiMessage(preset.bonkiLine)`
- Do NOT add as a layer (this is just a preview/audition)

**3. Preset add handler (add as layer):**

`handlePresetAdd(preset)`:
- Add preset as a new layer: `addLayer(layers, { id: \`preset-${preset.id}\`, name: preset.name, type: 'preset', code: preset.code, active: true })`
- Update layers state with the result
- Set BPM: `setBpm(preset.bpm)` and `evaluate(\`setcps(${bpmToCps(preset.bpm)})\`)`
- Evaluate all layers (including the newly added preset)
- Show Bonki speech bubble: `setBonkiMessage(preset.bonkiLine)`
- Set `isPlaying(true)`

**4. Render PresetGallery inside SEQUENCE tab:**

In `renderTabContent()`, when `activeTab === 'SEQUENCE'`, render:
```jsx
<>
  <PresetGallery
    onPresetSelect={handlePresetSelect}
    onPresetAdd={handlePresetAdd}
  />
  <Sequencer grid={grid} onToggleCell={handleToggleCell} stepCount={stepCount} />
</>
```

This places the gallery ABOVE the sequencer grid inside the SEQUENCE tab, per locked decision.

**5. Render BonkiSpeech:**

Add `<BonkiSpeech message={bonkiMessage} />` in the App render, positioned after Transport. The BonkiSpeech component handles its own auto-dismiss, but also wire `setBonkiMessage(null)` as a cleanup. The component uses `useEffect` internally with a 3-second timer.

**6. Make the "+" add button always visible on touch devices:**

On mobile/tablet where hover doesn't exist, the "+" button on preset cards should always be visible. Add a media query:
```css
@media (hover: none) {
  .preset-card-add {
    opacity: 1;
  }
}
```
