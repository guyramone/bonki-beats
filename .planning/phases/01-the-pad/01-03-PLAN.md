  <action>
    Create `src/utils/` directory if it doesn't exist.

    **src/utils/patterns.js:** Define sound constants and pattern generation logic.

    **SOUNDS array (for sequencer rows):**
    ```javascript
    export const SOUNDS = [
      { name: 'Kick', sample: 'RolandTR808_bd' },
      { name: 'Snare', sample: 'RolandTR909_sd' },
      { name: 'Hi-hat', sample: 'RolandTR808_hh' },
      { name: 'Clap', sample: 'RolandTR808_cp' },
    ];
    ```

    **sequencerToPattern(grid, sounds) function:**
    - Takes `grid` (2D boolean array: rows x steps) and `sounds` (SOUNDS array)
    - For each row, maps `true` → `x` and `false` → `~`, joins with spaces
    - Generates Strudel code: `s("soundName").struct("x ~ ~ ~ x ~ ~ ~")`
    - Wraps all rows in `stack(...)`
    - Returns the pattern string
    - If ALL cells are off, return empty string (no pattern to play)
    - Example output:
      ```
      stack(s("RolandTR808_bd").struct("x ~ ~ ~ x ~ ~ ~"), s("RolandTR909_sd").struct("~ ~ x ~ ~ ~ x ~"), s("RolandTR808_hh").struct("~ ~ ~ ~ ~ ~ ~ ~"), s("RolandTR808_cp").struct("~ ~ ~ ~ ~ ~ ~ ~"))
      ```

    **PADS array (16 pad presets):**
    Define 16 pads in a flat array, each with `{ id, label, pattern, color }`:

    Row 1 — Drums (warm accent):
    - Kick: `s("RolandTR808_bd")`
    - Snare: `s("RolandTR909_sd")`
    - Hi-hat: `s("RolandTR808_hh")`
    - Open hat: `s("RolandTR808_oh")`

    Row 2 — Percussion (warm accent):
    - Clap: `s("RolandTR808_cp")`
    - Rimshot: `s("RolandTR909_rim")`
    - Cowbell: `s("RolandTR808_cb")`
    - Tom: `s("RolandTR808_ht")`

    Row 3 — Patterns (cool accent):
    - 4-on-floor: `s("RolandTR808_bd").fast(4)`
    - Backbeat: `s("RolandTR909_sd").struct("~ x ~ x")`
    - Hi-hat groove: `s("RolandTR808_hh").fast(8)`
    - Funky kick: `s("RolandTR808_bd").struct("x ~ x ~ ~ x ~ ~")`

    Row 4 — Weird/Fun (primary accent):
    - Synth stab: `note("c3 e3 g3").s("sawtooth").cutoff(800)`
    - Bass: `note("c2").s("sawtooth").cutoff(400).gain(0.8)`
    - Blip: `note("c5 e5").s("triangle").decay(0.05).sustain(0)`
    - Chaos: `s("RolandTR808_bd RolandTR909_sd RolandTR808_hh RolandTR808_cp").fast(2).sometimes(rev)`

    Assign color categories: `'warm'` for drums/perc, `'cool'` for patterns, `'gold'` for weird/fun. These map to CSS accent variables.

    **DEFAULT_GRID constant:**
    ```javascript
    export const STEP_COUNT = 8;
    export const DEFAULT_GRID = SOUNDS.map(() => Array(STEP_COUNT).fill(false));
    ```
  </action>

  </verify>
