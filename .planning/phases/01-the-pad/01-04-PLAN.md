  <action>
    **Rendering approach: Inline SVG pixel art** (best balance of quality, scalability, and no external file dependency).

    **Why SVG over CSS box-shadow or PNG sprite:**
    - SVG scales perfectly at any size without blur (better than PNG)
    - More readable and maintainable than 1024 box-shadow entries (better than CSS pixel art)
    - No external file to load (better than PNG sprite sheet for Phase 1)
    - Can be embedded directly in JSX
    - Animations via CSS classes work perfectly with SVG
    - Can be swapped for a proper sprite sheet later without changing the component API

    **src/components/Bonki.jsx:**
    - Props: `state` (string: 'idle' | 'vibing', default 'idle')
    - Imports `./styles/bonki.css` (wait — import from `../styles/bonki.css` to match file structure)
    - Renders an inline SVG that represents Bonki at approximately 32x32 logical pixels, displayed at 48x48 CSS pixels
    - The SVG should depict a simplified, charming black cat with:
      - Round head silhouette (Scottish Fold = no pointed ears, rounded dome shape)
      - Fold ears: small curved bumps on top of the round head
      - Big golden amber eyes (#f5a623): THE focal point, round, expressive
      - Compact body: sitting loaf shape
      - Small DJ headphones suggestion: thin arc over the head in accent color
      - Minimal detail — this is a small character, clarity over complexity
      - Whiskers: 2-3 thin lines on each side
    - Wrap SVG in a `<div className={`bonki bonki-${state}`}>` for CSS animation targeting
    - Use `image-rendering: pixelated` on the container for crisp pixel feel if desired, but since this is SVG it will be clean at any size
    - SVG viewBox="0 0 32 32", rendered at width/height 48px

    **Design the SVG as a grid of rectangles (pixel art style):**
    Each "pixel" is a 1x1 rect in the SVG viewBox. Build Bonki's silhouette using rect elements:

    Simplified pixel layout (conceptual — implement as actual SVG rects):
    - Head: cluster of black (#1a1a1a) rects forming round shape, rows ~6-16, cols ~8-24
    - Fold ears: two small black bumps at top of head, rows 5-7
    - Eyes: two golden (#f5a623) rects/circles, ~3x3 pixels each, rows 10-12, symmetrically placed
    - Eye highlight: tiny white (#ffffff) 1px rect in each eye's upper corner (Ghibli touch)
    - Headphones: thin arc of rects in accent-cool color (#6b9080) over the head, rows 4-6
    - Headphone cups: small colored rectangles on sides of head
    - Body: wider cluster of black rects below head, rows 17-28, loaf shape
    - Whiskers: very thin (0.5px stroke) lines in light gray

    Keep it simple — maybe 50-80 rects total, not a full 1024-pixel grid. This is a SMALL character in the corner. Charm over detail.

    **Alternative (simpler path if SVG pixel art is too complex):** Build Bonki as a CSS-only character using a single div with:
    - Rounded body shape (border-radius)
    - Two golden eye dots (::before and ::after pseudo-elements or child divs)
    - Headphone arc (border on a pseudo-element)
    - This gives a stylized, not pixel-art, look — but may actually fit the TE aesthetic better

    **Decision for executor:** Try SVG pixel art first. If it takes more than 30 minutes to get looking good, fall back to CSS-only stylized Bonki. Either way, the component API stays the same: `<Bonki state="idle" />`.

    **src/styles/bonki.css:**

    Container styles:
    ```css
    .bonki {
      display: flex;
      align-items: center;
      justify-content: center;
      width: 48px;
      height: 48px;
      flex-shrink: 0;
      transition: transform 0.3s ease;
    }

    .bonki svg {
      width: 100%;
      height: 100%;
    }
    ```

    **Idle animation (slow blink):**
    - Every 3-4 seconds, Bonki's eyes briefly close (opacity 0 on eye elements) for 200ms
    - Subtle body sway: very gentle `translateY` oscillation (1-2px) over 4s
    - Implementation: CSS animation on the `.bonki-idle` class
    ```css
    .bonki-idle {
      animation: bonki-breathe 4s ease-in-out infinite;
    }

    @keyframes bonki-breathe {
      0%, 100% { transform: translateY(0); }
      50% { transform: translateY(-2px); }
    }

    .bonki-idle .bonki-eyes {
      animation: bonki-blink 4s ease-in-out infinite;
    }

    @keyframes bonki-blink {
      0%, 90%, 100% { opacity: 1; }
      95% { opacity: 0; }
    }
    ```

    **Vibing animation (head bob to music):**
    - Rhythmic up-down bounce synced to a musical tempo feel (~120 BPM = 500ms per beat)
    - Slight rotation on the bob for personality (±3deg)
    - Eyes stay open, slightly wider (transform scale on eyes)
    ```css
    .bonki-vibing {
      animation: bonki-vibe 500ms ease-in-out infinite;
    }

    @keyframes bonki-vibe {
      0%, 100% { transform: translateY(0) rotate(0deg); }
      25% { transform: translateY(-3px) rotate(-2deg); }
      75% { transform: translateY(-1px) rotate(2deg); }
    }

    .bonki-vibing .bonki-eyes {
      animation: none; /* Stop blinking while vibing */
      opacity: 1;
    }
    ```

    Hover state (for future interactivity):
    ```css
    .bonki:hover {
      cursor: pointer;
      transform: scale(1.1);
    }
    ```
