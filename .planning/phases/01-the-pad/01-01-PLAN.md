  <action>
    **src/main.jsx:** Create the React entry point that:
    1. Imports `React`, `ReactDOM`, `App`
    2. Imports `initStrudel` from `@strudel/web`
    3. Imports a global CSS file `./styles/index.css` (will be created in Plan 01-02; create an empty placeholder now)
    4. Renders `<App />` into `#root` using `createRoot`
    5. Exports or exposes `initStrudel` call — BUT do NOT call it on page load. Strudel requires a user gesture (click/tap) to start Web Audio. Instead, create and export an async `initAudio()` function that:
       - Calls `await initStrudel({ prebake: async () => { await samples('https://raw.githubusercontent.com/felixroos/dough-samples/main/tidal-drum-machines.json') } })`
       - Sets a module-level `initialized` flag to prevent double-init
       - Returns the initialized state
    6. The App component will call `initAudio()` on first user interaction (handled in Plan 01-02/01-03)

    NOTE: The `samples` function is available from `@strudel/web` — import it alongside `initStrudel`.

    **src/App.jsx:** Create a minimal placeholder component:
    - Returns a `<div className="app">` with text "HOMIE Beats" and a temporary "Initialize Audio" button
    - The button calls `initAudio()` from main.jsx on click (to verify Strudel works)
    - Show initialization state: "Ready to initialize" → "Loading..." → "Ready! Strudel initialized."
    - Use React `useState` for init state tracking
    - This placeholder will be REPLACED entirely in Plan 01-02 with the real tabbed UI

    **src/styles/index.css:** Create empty placeholder file (populated in Plan 01-02).

    **Audio initialization pattern (CRITICAL):**
    ```jsx
    // main.jsx
    import { initStrudel, samples } from '@strudel/web';

    let initialized = false;

    export async function initAudio() {
      if (initialized) return true;
      await initStrudel({
        prebake: async () => {
          await samples('https://raw.githubusercontent.com/felixroos/dough-samples/main/tidal-drum-machines.json');
        }
      });
      initialized = true;
      return true;
    }
    ```

    Register iOS touch activation for :active pseudo-class:
    ```javascript
    document.body.addEventListener('touchstart', () => {}, { passive: true });
    ```
