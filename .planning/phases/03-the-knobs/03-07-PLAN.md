    **localStorage.js** — Safe localStorage helpers:

    1. `saveState(key, value)`:
       - JSON.stringify and store. Catch and log errors (quota exceeded, etc.)
       - All keys prefixed with `homie-beats-`
    2. `loadState(key, defaultValue)`:
       - Read, JSON.parse, return. On error or missing, return defaultValue.
    3. `clearState(key)`:
       - Remove the key. If no key provided, remove all `homie-beats-` prefixed keys.
    4. Keys used:
       - `homie-beats-session` — full session state (rows, BPM, stepCount, etc.)
       - `homie-beats-favorites` — sound favorites (already used by useSoundBrowser)
       - `homie-beats-recents` — recent sounds (already used by useSoundBrowser)

    **useSessionPersistence.js** — Custom hook for auto-save/restore:

    1. Takes: `{ rows, bpm, stepCount, volume, rootNote, scaleName, masterEffects, globalTransforms, sections }`.
    2. **Save:** Debounced save (500ms after last change) to `homie-beats-session`. Only save serializable state (no functions, no audio refs).
       - Serialize rows: strip any non-serializable fields. Pattern.steps is boolean[], sound is object, effects is object — all serializable.
       - Save: `{ rows, bpm, stepCount, volume, rootNote, scaleName, masterEffects, globalTransforms, sections, savedAt: Date.now() }`.
    3. **Restore:** On mount, load from `homie-beats-session`.
       - Return the loaded state as initial values.
       - If no saved state, return null (use defaults).
       - Do NOT auto-play on restore (user must tap play — browser autoplay policy).
    4. **Clear:** `clearSession()` function to reset to defaults (for a "New Session" button).
    5. Export `useSessionPersistence` hook and `loadInitialState()` function.

    **App.jsx — Integration:**

    1. On mount: call `loadInitialState()` to get saved state.
    2. Initialize `rows`, `bpm`, `stepCount`, `volume`, `rootNote`, `scaleName`, `masterEffects`, `globalTransforms`, `sections` from saved state or defaults.
    3. Call `useSessionPersistence(currentState)` — auto-saves on changes.
    4. Add "New Session" button (in control strip or menu) that calls `clearSession()` and resets all state to defaults.
    5. On HUSH: reset rows to defaults but DON'T clear localStorage (user might want to reload their session after a panic stop). Only "New Session" clears persistence.
