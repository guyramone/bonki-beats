<objective>
Build the scale/melodic sequencing system and euclidean rhythm generator. Scale picker with visual keyboard lets users choose root + scale type, with note labels showing names and degrees. Euclidean control provides +/- steppers with a circular visual preview. Both unlock melodic and rhythmic creativity beyond basic drum patterns.

Purpose: Scale picker transforms sequencer from "drums only" to "melodies too" — kids see which notes are in a scale, tap the keyboard to hear them, and build melodies row by row. Euclidean rhythms let kids discover world music patterns instantly (Cuban tresillo, West African bell, Bossa Nova).

Output: ScalePicker.jsx, EuclideanControl.jsx, scaleData.js, scale-picker.css, App.jsx wiring
</objective>

    **scaleData.js** — Scale data and note math:

    1. `NOTE_NAMES` — ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B']
    2. `SCALE_NAMES` — Curated list of ~30 most useful scales for the UI (from the 92 available):
       Organized in groups for the dropdown:
       - **Common:** major, minor, harmonic minor, melodic minor
       - **Pentatonic:** major pentatonic, minor pentatonic, blues
       - **Modal:** dorian, phrygian, lydian, mixolydian, locrian, aeolian
       - **Jazz:** bebop, altered, lydian dominant, whole tone
       - **World:** hungarian minor, flamenco, persian, arabic, egyptian, hirajoshi, pelog, in-sen
       - **Exotic:** chromatic, diminished, half-whole diminished, enigmatic
       Full list accessible via "Show all scales" toggle (loads remaining ~60 from @tonaljs/tonal).
    3. `getScaleNotes(root, scaleName)` — returns array of note objects:
       ```
       [{ note: 'C', degree: 1, octave: 3, inScale: true }, { note: 'C#', degree: null, octave: 3, inScale: false }, ...]
       ```
       Uses Strudel's scale system format: `"Root:ScaleName"` (e.g., `"C:minor pentatonic"`).
       For the visual keyboard, compute which of the 12 chromatic notes are "in scale" based on the scale intervals. Use the standard music theory interval patterns:
       - major: [0,2,4,5,7,9,11]
       - minor: [0,2,3,5,7,8,10]
       - etc.
       Store interval sets for each scale name.
    4. `noteToString(noteName, octave)` — returns "C3", "D#4", etc.
    5. `SCALE_INTERVALS` — map of scale name to semitone interval array for the common scales. For less common scales, compute from @tonaljs/tonal at runtime.
    6. `getScaleDegreeLabel(note, root, scaleName)` — returns "C=1" or "D=2" etc. for in-scale notes.

    **EuclideanControl.jsx** — Pulses/steps steppers with circular visual preview:

    1. Props: `{ pulses, steps, rotation, onChange, size, color }`.
       - `size` default: 64 (preview ring diameter)
       - `color` default: row color
    2. Layout (horizontal flex):
       a. **SVG Ring Preview** (left side):
          - Circle of `steps` dots arranged evenly around a ring
          - Active dots (pulses) filled with `color`, larger (r=4)
          - Inactive dots dimmed, smaller (r=2)
          - Use Bjorklund algorithm to determine which dots are active:
            Simple implementation: distribute `pulses` hits as evenly as possible across `steps` slots.
            ```javascript
            function bjorklund(pulses, steps) {
              // Euclidean rhythm algorithm
              if (pulses >= steps) return Array(steps).fill(true);
              if (pulses <= 0) return Array(steps).fill(false);
              // ... standard Bjorklund implementation
            }
            ```
          - Apply rotation: shift the pattern by `rotation` positions
          - Connecting lines between consecutive active dots (thin arcs) for visual rhythm flow
       b. **Controls** (right side, vertical stack):
          - Pulses row: "-" button, value display, "+" button. Range: 0 to steps.
          - Steps row: "-" button, value display, "+" button. Range: 1 to 32.
          - Rotation row (optional, show if pulses > 0): "-" button, value, "+" button. Range: 0 to steps-1.
       c. **Named rhythm hint:** if the current pulses/steps combo matches a known rhythm, show its name below:
          - (3,8) → "Tresillo"
          - (5,8) → "Cinquillo"
          - (7,12) → "West African Bell"
          - (4,9) → "Turkish Aksak"
          - (5,16) → "Bossa Nova"
          - (3,4) → "Afro-Cuban"
          - (2,5) → "Khafif-e-ramal"
    3. `onChange({ pulses, steps, rotation })` called on any stepper change.
    4. Stepper buttons: 32px, clear +/- labels, touch-friendly.
    5. Disable mode: if row has manual step pattern (non-euclid), show a "Switch to Euclidean" button instead. Switching clears the manual pattern.
