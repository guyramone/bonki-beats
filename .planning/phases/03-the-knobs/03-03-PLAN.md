<objective>
Build the sound browser: a full-screen modal that lets users explore and select sounds across drum machine banks, synth engines, and GM soundfonts. Visual category grid with colorful tiles, three-level drill-down, tap-to-preview, double-tap-to-select, favorites, recents, and dice button.

Purpose: This is how kids (and Chris) discover sounds beyond the default TR-808. The browser makes 600+ drum samples, 7 synth engines, and 128 GM soundfonts accessible through an app-store-like browsing experience. Sound selection updates the row model from Plan 01.

Output: SoundBrowser.jsx, SoundCategoryGrid.jsx, soundCatalog.js, useSoundBrowser.js, sound-browser.css
</objective>

           ... (include top 15-20 drum machines from tidal-drum-machines.json — full list in research)
         ]
       }

       Use colorful pixel-art style icons per category. Since actual pixel art SVGs are complex, use emoji placeholders with CSS-styled colored tile backgrounds. Categories:
       - Drums (red-warm) — TR-808, TR-909, LinnDrum, LinnLM1, CR-78, DMX, SP-12, etc.
       - Keys (blue) — gm_piano, gm_epiano1, gm_epiano2, gm_organ, gm_harpsichord, gm_clavinet
       - Strings (purple) — gm_strings, gm_pizzicato_strings, gm_fiddle
       - Bass (green) — gm_bass, gm_synth_bass
       - Brass (gold) — gm_trumpet, gm_trombone, gm_french_horn, gm_tuba
       - Woodwinds (teal) — gm_flute, gm_clarinet, gm_oboe, gm_sax
       - Synths (cyan) — engine bank: saw, square, sine, triangle, supersaw, pink noise, white noise
       - Pads (indigo) — gm_pad variants (warm, polysynth, choir, metallic, etc.)

    2. Each bank has `type: 'sample' | 'synth' | 'soundfont'`.
    3. Synth bank contains engines as "sounds": `{ id: 'saw', name: 'Sawtooth', type: 'synth' }`, etc.
    4. Soundfont banks: type is 'soundfont'. Sound names correspond to GM instrument numbers (e.g., `{ id: 'gm_piano', name: 'Acoustic Grand Piano', n: 0 }`).
    5. `getSoundsForBank(bankId)` — returns the sounds array for a given bank.
    6. `getRandomSound()` — picks a random category, random bank, random sound. Returns `{ type, bank, name, n }` matching row.sound shape.
    7. `soundToLabel(sound)` — returns human-readable name for a sound object.

    **useSoundBrowser.js** — Custom hook managing browser navigation state:

    1. State: `{ level: 'categories' | 'banks' | 'sounds', selectedCategory, selectedBank, searchQuery }`.
    2. `favorites` — Set of sound IDs (stored as "type:bank:name"), persisted to localStorage key `homie-beats-favorites`.
    3. `recents` — Array of last 20 selected sounds, persisted to localStorage key `homie-beats-recents`. New selections push to front, duplicates removed.
    4. `toggleFavorite(soundId)` — add/remove from favorites, save to localStorage.
    5. `addToRecents(sound)` — push sound to front of recents, cap at 20, save to localStorage.
    6. `navigateToCategory(categoryId)` — set level to 'banks', selectedCategory.
    7. `navigateToBank(bankId)` — set level to 'sounds', selectedBank.
    8. `navigateBack()` — go up one level.
    9. `reset()` — return to category level.
    10. Load favorites and recents from localStorage on mount.

    **SoundBrowser.jsx** — Full modal overlay with three-level drill-down:

    1. Props: `{ isOpen, onClose, onSelect, currentSound, onBonkiReaction }`.
       - `onSelect(sound)` — called with sound object matching row.sound shape
       - `currentSound` — the row's current sound (for highlighting)
       - `onBonkiReaction(message)` — triggers Bonki speech
    2. Uses `useSoundBrowser()` hook for navigation state.
    3. Layout: full-screen overlay with dark semi-transparent backdrop. Modal content area: header (title, back button, close X), content body, footer (dice button).
    4. **Level 1 — Categories:**
       - Show Favorites section at top (if any favorites exist): horizontal scroll of small tiles
       - Show Recents section (if any recents exist): horizontal scroll of small tiles
       - Then SoundCategoryGrid with all categories
    5. **Level 2 — Banks:**
       - Header shows category name + back arrow
       - List of banks in the selected category as rows: bank name, number of sounds badge
       - Tap a bank → navigate to sounds level
    6. **Level 3 — Sounds:**
       - Header shows bank name + back arrow
       - Grid/list of individual sounds
       - Each sound: name, heart toggle (favorite), play preview button
       - **Single tap** on a sound → preview it: evaluate the sound as a one-shot (e.g., `s("RolandTR808_bd")` or `note("c3").s("supersaw")`) — plays once and stops
       - **Double tap** on a sound → select it: call `onSelect(soundObject)`, add to recents, close browser. Trigger Bonki reaction.
       - Currently selected sound (matching currentSound) gets a highlight border.
    7. **Dice button** in footer: calls `getRandomSound()`, previews it, shows Bonki reaction ("ooh, wild pick!" or similar). Second tap on dice selects the random sound.
    8. **Bonki reactions** on selection (hardcoded, category-based):
       - Drums: "classic!", "that's the one!", "boom!"
       - Synths: "ooh, synthesized!", "buzzy!"
       - Soundfonts: "fancy!", "orchestral vibes!"
       - Weird: "now we're talking!", "bonkers!"
       - Random/dice: "surprise!", "wild card!"
    9. Close on: X button, backdrop click, or double-tap select.
    10. CSS transitions: slide up on open, slide down on close (200ms ease).
