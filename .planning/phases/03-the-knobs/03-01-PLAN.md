    **codeGenerator.js** — Pure functions converting row model to Strudel code:

    1. `rowToCodeLine(row, stepCount, globalScale)` — converts one row to a Strudel code line:
       - If row.muted, return null
       - Sound source: sample → `s("bank_name")`, synth → `note("noteOctave").s("engine")`, soundfont → `note("noteOctave").s("fontName")`
       - Pattern: euclid → `.euclid(pulses, steps)` or `.euclidRot(pulses, steps, rotation)`, otherwise → `.struct("x ~ x ...")`
       - Effects: only emit active effects with non-default values. Chain in order: filter → delay → reverb → distort → crush/coarse → pan
       - Transforms: reverse → `.rev()`, speed → `.fast(N)`, degradeBy → `.degradeBy(N)`, swing → `.swing(N)`
       - Volume: `.gain(N)` if < 1.0
       - Scale: `.scale("Root:ScaleName")` if globalScale set and row is melodic
       - Orbit: `.orbit(rowIndex + 1)` for each row (unique orbit per row per research recommendation)
    2. `rowsToStrudelCode(rows, stepCount, globalScale, masterEffects)` — converts all rows to full code:
       - Filter out muted rows and rows with no active cells (and no euclid pattern)
       - Map each to `rowToCodeLine()`
       - Wrap in `stack(...)`
       - Apply master effects outside the stack (djf, global room, global delay, global gain)
       - Return final code string
    3. `generateDisplayCode(rows, stepCount, globalScale)` — same as above but WITHOUT .gain() volume wrapper and WITHOUT master effects (clean code for code view display and copy/paste)
