    **Install dependency:**
    ```bash
    cd homie-beats && npm install --save-exact react-knob-headless@0.4.0
    ```
    Note: @use-gesture/react installs as peer dependency automatically.

    **Knob.jsx** — Styled wrapper around react-knob-headless with TE-inspired SVG visuals:

    1. Import `KnobHeadless` from `react-knob-headless`.
    2. Props: `{ label, value, min, max, onChange, onDoubleClick, unit, logScale, size, color, step, defaultValue, formatValue }`.
       - `size` default: 48 (minimum touch target per CONTEXT.md)
       - `color` default: use `--accent-primary` gold
       - `step` default: 1 for integers, 0.01 for floats (derived from range)
       - `formatValue` optional: custom display formatter (e.g., frequency to "2.4kHz")
    3. Logarithmic mapping for frequency knobs (cutoff, etc.):
       ```
       mapTo01 = logScale ? (v) => Math.log(v / min) / Math.log(max / min) : (v) => (v - min) / (max - min)
       mapFrom01 = logScale ? (n) => min * Math.pow(max / min, n) : (n) => min + n * (max - min)
       ```
    4. SVG visual (48x48 viewBox, scales with `size` prop):
       - Background track circle (subtle dark ring, `--surface-elevated`)
       - Value arc from -135deg to current angle (colored, glows when active)
       - Indicator line from center to edge at current angle (bright dot at tip)
       - Center circle with slight gradient (looks like a physical knob cap)
    5. Arc path helper: `describeArc(cx, cy, radius, startAngle, endAngle)` returns SVG path `d` attribute for the value arc. Range: -135deg (min) to +135deg (max), total 270deg sweep.
    6. Double-tap to reset: `onDoubleClick` prop calls `onChange(defaultValue)`. Wire to `onDoubleClick` on the container div.
    7. Active state: when dragging, add `.knob-active` class for glow effect.
    8. Drag sensitivity: `dragSensitivity={0.006}` for fine control (Ableton-style vertical drag).
    9. ARIA: `aria-label={label}`, `aria-valuemin={min}`, `aria-valuemax={max}`, `aria-valuenow={value}`, `role="slider"`.
    10. Value display: show formatted value above the knob in a small text element. Use `formatValue(value)` if provided, otherwise `Math.round(value) + (unit || '')`.
    11. Label display: show label text below the knob. Uppercase, small font, tracking, TE typography.

    **knobs.css** — Styles for knob, slider, and toggle components:

    1. `.knob-container` — flex column, align center, gap 2px, cursor: grab
    2. `.knob-svg` — width/height from size prop, pointer-events: none (interaction on KnobHeadless wrapper)
    3. `.knob-track` — subtle ring, stroke: `var(--surface-elevated)`, strokeWidth: 3
    4. `.knob-arc` — colored arc, stroke: `var(--knob-color, var(--accent-primary))`, strokeWidth: 3, strokeLinecap: round, fill: none. Transition: none (real-time updates must not lag).
    5. `.knob-indicator` — indicator line, stroke: `var(--text-primary)`, strokeWidth: 2
    6. `.knob-cap` — center circle, fill with subtle radial gradient (slightly lighter center), gives 3D feel
    7. `.knob-active .knob-arc` — filter: drop-shadow with knob color glow, increased opacity
    8. `.knob-value` — font-size: 10px, font-variant-numeric: tabular-nums, color: `var(--text-primary)`, min-height: 14px
    9. `.knob-label` — font-size: 9px, text-transform: uppercase, letter-spacing: 0.1em, color: `var(--text-secondary)`, min-height: 12px
    10. All text centered. Use system monospace for values (tabular alignment).

    **Slider.jsx** — Styled range input for volume/mix/gain levels:

    1. Props: `{ label, value, min, max, step, onChange, unit, color, formatValue, vertical }`.
       - `vertical` default: false. When true, renders vertically (for potential channel strip layout).
    2. Render as `<input type="range">` with custom CSS styling.
    3. Track: thin line (2px height), colored fill portion matches value position, unfilled portion is `--surface-elevated`.
    4. Thumb: 16px circle, colored, with subtle shadow. On touch, inflate to 24px (easier grab).
    5. Value display: show current value above slider.
    6. Label display: show label below slider.
    7. Use CSS `accent-color` for quick wins, but also provide full `::-webkit-slider-runnable-track` and `::-webkit-slider-thumb` overrides for TE look.
    8. Background gradient trick for fill: `background: linear-gradient(to right, color fillPercent%, surface rest%)`.
    9. Minimum height: 48px total container for touch target compliance.

    **ToggleSwitch.jsx** — Glowing bypass toggle for effects:

    1. Props: `{ active, onChange, label, color, size }`.
       - `size` default: 32 (compact but touchable in context of effects rack)
       - `color` default: `--accent-primary`
    2. Render as a `<button>` with toggle semantics:
       - When active: filled circle with colored glow, bright
       - When inactive: outlined circle, dim, no glow
    3. CSS: `.toggle-switch` base, `.toggle-switch.active` with box-shadow glow, background-color fill, transition 150ms ease.
    4. Glow: `box-shadow: 0 0 8px 2px var(--toggle-color)` when active.
    5. ARIA: `aria-pressed={active}`, `aria-label={label || 'Toggle'}`.
    6. Optional label text below the toggle.
    7. Click/tap toggles state via `onChange(!active)`.

    **knobs.css** — Add slider and toggle styles to the existing knobs.css:

    1. `.slider-container` — flex column, gap 2px, width: 100%
    2. `.slider-input` — full custom styling: height 48px (touch), appearance: none, background transparent
    3. `.slider-input::-webkit-slider-runnable-track` — height: 4px, border-radius: 2px, background: linear-gradient fill
    4. `.slider-input::-webkit-slider-thumb` — 16px circle, appearance: none, colored, -6px margin-top
    5. `.slider-input:active::-webkit-slider-thumb` — scale(1.5) for touch enlargement
    6. `.slider-value`, `.slider-label` — same typography as knob value/label
    7. `.toggle-switch` — border-radius: 50%, border: 2px solid, width/height: var(--toggle-size), cursor: pointer, transition: all 150ms ease
    8. `.toggle-switch.active` — background filled, box-shadow glow, border-color matches fill
    9. `.toggle-switch:not(.active)` — background transparent, border: dim, no glow
    10. Firefox slider track/thumb overrides (`::-moz-range-track`, `::-moz-range-thumb`)
