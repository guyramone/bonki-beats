Purpose: This is where "drum machine becomes instrument studio." Kids turn knobs and hear things change. The effects rack uses the Knob, Slider, and ToggleSwitch components from Plan 02, and updates the row model from Plan 01. Signal chain layout makes audio routing visual and educational.

Output: EffectsRack.jsx, RowControls.jsx, effects-rack.css, App.jsx wiring
</objective>

    **EffectsRack.jsx** — Full effects chain panel, rendered when row is expanded:

    1. Props: `{ row, rowIndex, onEffectChange, onTransformChange, color }`.
    2. Layout: horizontal signal chain flow (left to right on tablet+, stacked on mobile). Each effect is a "node" in the chain.
    3. **Signal chain nodes** (in order, connected by thin lines):

       **a. Filter Node:**
       - ToggleSwitch for active/bypass
       - Filter type selector: 3 buttons (LP / HP / BP), styled as segmented control
       - Cutoff knob: 48px, logScale=true, range 20-20000 Hz, format as "2.4k" for values >1000
       - Resonance knob: 48px, range 0-40
       - Envelope section (collapsible sub-area): Attack, Decay, Sustain, Release mini-knobs (36px each), Envelope depth knob
       - LFO section (collapsible): Rate and Depth mini-knobs

       **b. Delay Node:**
       - ToggleSwitch for active/bypass
       - Mix knob: 48px, range 0-1
       - Time knob: 48px, range 0.01-1s
       - Feedback knob: 48px, range 0-0.95
       - Sync toggle button: "SYNC" / "FREE" — when synced, time knob replaced by division selector
       - Division selector: segmented buttons (1/4, 1/8, 1/16, dotted variants)

       **c. Reverb Node:**
       - ToggleSwitch for active/bypass
       - Mix knob: 48px, range 0-1
       - Size knob: 48px, range 0.5-10
       - Type toggle: "ALGO" / "CONV" — algorithmic (.room) vs convolution (.ir)
       - When convolution selected: IR name selector dropdown (Cathedral, Plate, Spring — use available Strudel IRs)

       **d. Distortion Node:**
       - ToggleSwitch for active/bypass
       - Amount knob: 48px, range 0-10
       - Algorithm selector: dropdown/segmented showing all 9 types by name (from DISTORTION_TYPES)

       **e. Lo-Fi Node:**
       - Quick "Lo-Fi" ToggleSwitch (applies preset: crush=8, coarse=4)
       - Crush knob: 48px, range 1-16, labeled "BITS"
       - Coarse knob: 48px, range 1-32, labeled "RATE"

    4. **Connecting lines** between nodes: thin SVG lines or CSS borders. Glowing when the connected nodes are active.
    5. **Pan slider** at the end of the chain: horizontal, range 0-1, center default.
    6. **Randomize button**: small dice icon, calls a function that randomizes all effect params within musical ranges (cutoff 200-8000, resonance 0-15, delay 0-0.5, room 0-0.5, distort 0-3). Does NOT randomize sound or pattern.
    7. **Effect chain presets** row at top of rack: 3-4 preset buttons:
       - "Clean" — all effects off
       - "Gritty" — distort: 2, distorttype: 1, crush: 8
       - "Spacey" — delay: 0.4, delaytime: 0.25, room: 0.5, roomsize: 4
       - "Lo-Fi" — crush: 6, coarse: 4, cutoff: 2000
       Tapping a preset activates the relevant effects and sets values.
    8. All knob changes are throttled via requestAnimationFrame in the App's evaluate pipeline (not in EffectsRack itself — EffectsRack just calls callbacks).

    10. Mobile: nodes stack vertically, connectors become vertical lines

    **Sequencer.jsx** — Integrate RowControls and EffectsRack:

    1. Add `expandedRows` state (Set of expanded row indices).
    2. For each row, render:
       - The step grid (existing)
       - RowControls component inline (between label and grid, or below grid)
       - If row is in expandedRows → EffectsRack component below the row
    3. When a row is expanded, it should take more vertical space (context-sensitive allocation per CONTEXT.md). Other rows remain compact.
    4. Props from App: `onEffectChange`, `onTransformChange`, `onVolumeChange`, `onSoundBrowserOpen`, `onMuteToggle`.
    5. Muted rows: dim the row visually (opacity 0.4) and the row model's muted flag prevents code generation.

    **App.jsx** — Add effect change handlers and throttled evaluate:

    1. `handleEffectChange(rowIndex, paramPath, value)`:
       - Clone rows, set `rows[rowIndex].effects[paramPath] = value` (or nested for toggle active)
       - Call `scheduleEvaluate()`
    2. `handleTransformChange(rowIndex, param, value)`:
       - Clone rows, set `rows[rowIndex].transforms[param] = value`
       - Call `scheduleEvaluate()`
    3. `handleRowVolumeChange(rowIndex, value)`:
       - Clone rows, set `rows[rowIndex].volume = value`
       - Call `scheduleEvaluate()`
    4. `handleMuteToggle(rowIndex)`:
       - Clone rows, toggle `rows[rowIndex].muted`
       - Call `scheduleEvaluate()`
    5. **Throttled evaluate pipeline** — create `useThrottledEvaluate` hook or inline:
       - Uses a ref (`pendingEvalRef`) and requestAnimationFrame
       - When `scheduleEvaluate()` is called, if no pending rAF, schedule one
       - In the rAF callback: read current rows from ref, generate code, evaluate
       - This ensures knob drags at 60fps only evaluate ~15-20 times/sec (one per frame)
       - Store `rows` in a ref that updates on every state change (for freshness)
    6. Update existing `handleToggleCell` to use the throttled pipeline.
    7. Pass all handlers down to Sequencer as props.
