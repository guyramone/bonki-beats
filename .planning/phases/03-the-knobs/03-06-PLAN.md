<objective>
Build the master effects strip (always visible above transport) with DJ filter, global reverb/delay, and master volume. Plus global pattern transform controls (swing, probability, reverse, speed) with per-row overrides.

Purpose: Master strip gives the "DJ feel" — the DJ filter is the crowd-pleaser (per CONTEXT.md). Global transforms apply a consistent feel to the whole mix while per-row overrides let advanced users fine-tune. The master strip is always visible, making it the quickest way to shape the overall sound.

Output: MasterStrip.jsx, DJFilter.jsx, TransformControls.jsx, master-strip.css, App.jsx wiring
</objective>

    **TransformControls.jsx** — Pattern transform panel for effects rack (per-row overrides):

    1. Props: `{ transforms, globalTransforms, onChange, color }`.
       - `transforms`: the row's transform overrides (null values = use global)
       - `globalTransforms`: current global defaults
    2. Layout: horizontal row of controls:
       a. Swing: Knob, range 0-1. Shows "(global)" label when row value is null (using global default). When user starts adjusting, switches to per-row override.
       b. Probability: Knob (degradeBy), range 0-1. Same global/override behavior.
       c. Speed: Knob, range 0.25-4 (stepped: 0.25, 0.5, 1, 2, 4). Maps to `.fast()`.
       d. Reverse: ToggleSwitch. When active, pattern plays backwards via `.rev()`.
    3. Each control shows whether it's using global default or per-row override (subtle indicator: "G" badge when global, no badge when overridden).
    4. Double-tap on an overridden knob → resets to null (reverts to global).

    **App.jsx — Full master/transform wiring:**

    1. Add `globalTransforms` state: `{ swing: 0, degradeBy: 0, speed: 1, reverse: false }`.
    2. Add `masterEffects` state (expand from existing): `{ djf: 0.5, room: 0, delay: 0, volume: 1 }`.
    3. `handleMasterEffectChange(param, value)`:
       - Update masterEffects[param]
       - Call scheduleEvaluate()
    4. `handleGlobalTransformChange(param, value)`:
       - Update globalTransforms[param]
       - Call scheduleEvaluate()
    5. `handleRowTransformChange(rowIndex, param, value)`:
       - Update rows[rowIndex].transforms[param] = value (or null to revert to global)
       - Call scheduleEvaluate()
    6. Update `rowsToStrudelCode` call to pass globalTransforms.
    7. **Code generator update** — in codeGenerator.js, update `rowToCodeLine`:
       - For each transform param, use row.transforms[param] if not null, otherwise use globalTransforms[param].
       - Only emit transform code if the effective value is non-default.

    **EffectsRack.jsx** — Add TransformControls section:

    1. Add TransformControls after the effects chain nodes in the effects rack.
    2. Pass row.transforms, globalTransforms, and onChange handler.
    3. Label section: "TRANSFORMS" or "PATTERN".

    3. Transport bar remains at bottom, master strip sits directly above it.
